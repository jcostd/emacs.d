* Ascetic Emacs

This is my personal Emacs configuration.

Let's be clear upfront: *This is not a framework. This is not a distribution.* Unlike previous projects, this repository exists solely to version control my personal tool. It is engineered specifically for my workflow, my aesthetic, and my brain.

You are highly encouraged to read the code, understand the decisions, and steal the snippets you find useful. However, *I will not accept feature requests, and Pull Requests altering my workflow will be closed.*

* Philosophy

Built on Emacs 30+, this configuration follows strict architectural guidelines:

- *Native over Bloat:* If Emacs has a native solution (Tab-bar, Eglot, Flymake, Completion-preview), external packages are discarded.  Three survive, for want of a regexp mode in core: =go-mode=, =yaml-mode=, =web-mode=.
- *Acme Inspired:* Text is text. UI chrome, scrollbars, toolbars, and artificial visual boundaries are stripped away.
- *Clarity through Renunciation:* The UI relies on custom =ascetic= themes. Structure comes from regexp font-lock, rendered entirely via typography (bold/italic); no tree-sitter, by design. Color is strictly reserved for /signal/ (strings, constants, diagnostics, errors).
- *Zero Friction:* Deterministic window placement, instant completion feedback.

* Architecture

The configuration is strictly modular, separating logic from aesthetics.

- =init.el= :: The bootstrap sequence, package management, and core engine.
- =early-init.el= :: Pre-GUI and garbage collection optimizations.
- =lisp/ascetic-edit.el= :: Text objects, surround, line surgery, numbers.
- =lisp/ascetic-read.el= :: Overlay completion UI on =completing-read-function=.
- =lisp/ascetic-plumber.el= :: Routes completion candidates to processes and Lisp sinks.
- =lisp/ascetic-theme.el= :: Face engine shared by both themes.
- =themes/ascetic-dark-theme.el= :: Primary dark theme (Anthracite background, high-contrast signal).
- =themes/ascetic-light-theme.el= :: Primary light theme (Digital vellum, ink typography).

* Prerequisites

To run this exact setup, you need:

- GNU Emacs 30.2+.  No tree-sitter needed.
- macOS or GNU/Linux (runs on Slackware 15).
- Standard UNIX toolchain (=grep=, =find=, =git=); optional: =clangd=, =gopls=, =ruby-lsp=, =biber=.
 
* Stealing this config

If you want to clone it to test it or use it as a base for your own ascetic journey:

#+BEGIN_SRC shell
git clone https://github.com/jcostd/emacs.d.git ~/.emacs.d
#+END_SRC

Upon first launch, Emacs pulls the three packages above from NonGNU ELPA.  Nothing else touches the network.
